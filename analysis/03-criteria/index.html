收敛准则：单调有界与柯西

前两章的方法都要先知道极限是多少，再去验证。可很多数列的极限事先根本猜不出来，比如 (1 + 1/n)ⁿ。这一章给出只看数列本身就能判断收敛的准则：单调有界定理、柯西收敛准则和致密性定理。它们都依赖实数的完备性，在有理数里不成立。

§1

单调有界定理

一个数列只升不降，又不能超过某个数，它最终会停在哪里？答案是它所有项的上确界。这需要实数的一条基本性质。

确界原理（实数完备性）

非空且有上界的实数集必有上确界 β = sup S，即最小的上界。它有两条刻画：

(i) 对所有 s ∈ S，s ≤ β；　(ii) 任给 ε > 0，β − ε 不再是上界，即存在 s ∈ S 使 s > β − ε。

定理 3.1（单调有界定理）

单调递增且有上界的数列必收敛，极限是 \(\sup\{a_n\}\)。单调递减且有下界的数列同理，极限是下确界。

实验 1 · 越过 β − ε 的那一项β − ε 不是上界，所以总有一项越过它；单调性让后面的项都跟上
第 1 步 · 候选极限

数列有上界，由确界原理，\(\beta=\sup\{a_n\}\) 存在。我们证明 \(a_n\to\beta\)。

第 2 步 · 越过 β − ε

任给 ε > 0，由刻画 (ii)，存在某一项 \(a_N\gt\beta-\varepsilon\)。

第 3 步 · 单调性收尾

当 n > N 时，由单调递增和刻画 (i)，

\[\beta-\varepsilon\lt a_N\le a_n\le\beta\lt\beta+\varepsilon,\]

即 \(|a_n-\beta|\lt\varepsilon\)。∎

例：递推数列求极限

对 \(a_1=0\)，\(a_{n+1}=\sqrt{2+a_n}\)：用归纳法可证 \(a_n\lt2\)（若 \(a_n\lt2\)，则 \(a_{n+1}\lt\sqrt4=2\)）和 \(a_n\lt a_{n+1}\)（因为 \(a_n\lt2\) 时 \(a_n^2\lt a_n+2\)）。单调有界，所以收敛。设极限为 L，对递推式两边取极限得 \(L=\sqrt{2+L}\)，解得 L = 2（舍去负根）。

顺序很重要：必须先证明收敛，才能对递推式两边取极限。否则对 \(a_{n+1}=2a_n\)、\(a_1=1\) 也能“解出” L = 0，而这个数列明明趋于无穷。

在有理数里，这个定理不成立：1, 1.4, 1.41, 1.414, … 都是有理数，单调递增且小于 2，但它的极限 √2 不是有理数。确界原理正是实数比有理数多出来的东西。

§2

重要极限 e

本金 1 元，年利率 100%。一年结算一次，年底得 2 元；半年结算一次，得 \((1+\frac12)^2=2.25\) 元；结算越频繁，钱越多。但会不会无限多？

实验 2 · 一个从下往上，一个从上往下uₙ = (1 + 1/n)ⁿ 递增，vₙ = (1 + 1/n)ⁿ⁺¹ 递减，e 被夹在中间
第 1 步 · 单调递增

对 n 个 \(1+\frac1n\) 和一个 1 用均值不等式（几何平均 ≤ 算术平均）：

\[\sqrt[n+1]{\left(1+\tfrac1n\right)^n\cdot1}\lt\frac{n\left(1+\frac1n\right)+1}{n+1}=1+\frac1{n+1}.\]

两边 n + 1 次方，得 \(u_n\lt u_{n+1}\)。

第 2 步 · 有上界

二项式展开后，把每个因子 \(1-\frac jn\) 放大成 1：

\[u_n=\sum_{k=0}^{n}\frac{1}{k!}\left(1-\tfrac1n\right)\cdots\left(1-\tfrac{k-1}n\right)\le\sum_{k=0}^{n}\frac1{k!}\le1+1+\frac12+\frac1{2^2}+\cdots\lt3.\]

这里用到 k ≥ 1 时 \(k!\ge2^{k-1}\)。

第 3 步 · 定义 e

由单调有界定理，\(u_n\) 收敛。记

\[e=\lim_{n\to\infty}\left(1+\frac1n\right)^n\approx2.718281828.\]

又 \(v_n=u_n\left(1+\frac1n\right)\to e\cdot1=e\)。∎ 由于 \(u_n\) 严格递增，每个 \(u_n\lt e\)；用类似的均值不等式可证 \(v_n\) 严格递减，所以每个 \(v_n\gt e\)。

这里 e 是作为一个数列的极限被定义出来的。我们并不知道它的值，单调有界定理保证了它存在。这正是本章准则的用处。

§3

柯西收敛准则

单调有界定理只管单调数列。对一般数列，柯西的想法是：不问各项离极限多近，只问各项彼此离得多近。

定理 3.2（柯西收敛准则）

数列 \(\{a_n\}\) 收敛，当且仅当

\[\forall\,\varepsilon>0,\ \exists\,N,\ \forall\,m,n>N:\ |a_m-a_n|\lt\varepsilon\]

满足右边条件的数列叫柯西数列。和定义 1.1 对比：式子里没有 A。门槛之后的所有项挤在一个高度不到 ε 的窗口里，窗口放在哪里无所谓。

实验 3 · 柯西窗口窗口高度是 ε，位置由尾部的项自己决定

必要性：收敛 ⇒ 柯西

若 \(a_n\to A\)，对 ε/2 取门槛 N，则 m, n > N 时 \(|a_m-a_n|\le|a_m-A|+|A-a_n|\lt\varepsilon\)。充分性要难得多，需要 §4 的致密性定理，证明放在 §4 末尾。

用否定形式证明发散

“不是柯西数列”写成：\(\exists\,\varepsilon_0>0,\ \forall N,\ \exists\,m,n>N:\ |a_m-a_n|\ge\varepsilon_0\)。调和数列就是这样：

\[H_{2n}-H_n=\frac1{n+1}+\frac1{n+2}+\cdots+\frac1{2n}\ge n\cdot\frac1{2n}=\frac12.\]

取 ε₀ = 1/2，对任何 N，取 n = N + 1、m = 2n 即可。所以 Hₙ 发散，尽管相邻两项的差 1/(n + 1) 趋于 0。实验 3 里的 sin √n 也一样：相邻差趋于 0，但不是柯西数列。

下一节：从有界数列里挑出收敛的部分
§4

子列与致密性定理

从 \(\{a_n\}\) 中按下标递增的顺序挑出无穷多项 \(a_{n_1},a_{n_2},\dots\)（\(n_1\lt n_2\lt\cdots\)），得到子列 \(\{a_{n_k}\}\)。数列收敛于 A，当且仅当它的每个子列都收敛于 A。所以只要找到两个极限不同的子列，就能断定数列发散，例如 (−1)ⁿ 的奇数项和偶数项。

定理 3.3（致密性定理，Bolzano–Weierstrass）

有界数列必有收敛子列。

证明用二分法：把区间对半分，至少有一半含有数列的无穷多项，留下这一半，再分。区间一次次减半，套住一个点；每次从当前区间里挑一项，下标比上一次大，就得到收敛于这个点的子列。

实验 4 · 二分法挑子列数列 aₙ = sin n，在 [−1, 1] 里乱跳；用前 20 万项代表“无穷多项”

回到柯西准则：充分性的证明

第 1 步 · 柯西数列有界

对 ε = 1 取门槛 N，n > N 时 \(|a_n-a_{N+1}|\lt1\)。再加上前 N 项，和定理 2.2 一样得到有界。

第 2 步 · 挑出收敛子列

由致密性定理，存在子列 \(a_{n_k}\to A\)。

第 3 步 · 整个数列跟着收敛

任给 ε，取柯西条件的门槛 N，再取 k 足够大使 \(n_k>N\) 且 \(|a_{n_k}-A|\lt\varepsilon\)。当 n > N 时

\[|a_n-A|\le|a_n-a_{n_k}|+|a_{n_k}-A|\lt2\varepsilon.\]

所以 \(a_n\to A\)。∎

本章的三个准则一环扣一环：确界原理 ⇒ 单调有界定理；确界原理（或区间套）⇒ 致密性定理 ⇒ 柯西准则的充分性。它们都是实数完备性的不同说法。

练习题

练习 1　设 \(a_1=\sqrt2\)，\(a_{n+1}=\sqrt{2a_n}\)。证明 \(\{a_n\}\) 收敛并求极限。

提示

仿照 §1 的例子：归纳证明 aₙ < 2 和单调递增，再对递推式取极限。

参考答案

若 \(a_n\lt2\)，则 \(a_{n+1}=\sqrt{2a_n}\lt2\)；又 \(a_{n+1}^2-a_n^2=a_n(2-a_n)\gt0\)，故递增。单调有界，收敛。设极限为 L，由 \(L=\sqrt{2L}\) 且 \(L\ge\sqrt2\) 得 L = 2。

练习 2　用柯西准则证明 \(a_n=\displaystyle\sum_{k=1}^{n}\frac1{k^2}\) 收敛。

提示

k ≥ 2 时 \(\dfrac1{k^2}\lt\dfrac1{k(k-1)}=\dfrac1{k-1}-\dfrac1k\)，求和会裂项相消。

参考答案

设 m > n，则

\[0\lt a_m-a_n=\sum_{k=n+1}^{m}\frac1{k^2}\lt\sum_{k=n+1}^{m}\left(\frac1{k-1}-\frac1k\right)=\frac1n-\frac1m\lt\frac1n.\]

任给 ε，取 \(N=\lceil1/\varepsilon\rceil\)，m > n > N 时 \(|a_m-a_n|\lt\frac1n\lt\varepsilon\)。∎（它的极限是 π²/6，这是欧拉的结果，这里不需要。）

练习 3　求 \(\displaystyle\lim_{n\to\infty}\left(1+\frac1n\right)^{2n}\) 和 \(\displaystyle\lim_{n\to\infty}\left(1-\frac1n\right)^{n}\)。

提示

第一个用乘法法则。第二个写成 \(\left(\frac{n-1}{n}\right)^n=\dfrac{1}{\left(1+\frac{1}{n-1}\right)^{n}}\)。

参考答案

\(\left(1+\frac1n\right)^{2n}=\left[\left(1+\frac1n\right)^{n}\right]^2\to e^2\)。

\(\left(1-\frac1n\right)^{n}=\dfrac{1}{\left(1+\frac1{n-1}\right)^{n-1}\left(1+\frac1{n-1}\right)}\to\dfrac1{e\cdot1}=\dfrac1e\)。

练习 4　用“不是柯西数列”的形式证明 \(a_n=\ln n\) 发散。

提示

找一对下标，让差值是个固定的正数。

参考答案

取 ε₀ = ln 2。对任何 N，取 n = N + 1，m = 2n，则 \(|a_m-a_n|=\ln2n-\ln n=\ln2\ge\varepsilon_0\)。所以 \(\ln n\) 不是柯西数列，发散。∎
