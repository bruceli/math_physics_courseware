极限：ε-N 与 ε-δ

“无限接近”是一种直觉，还不是证明。这一章把它翻译成一句可以检验的话：不管别人给出多小的误差 ε，你总能找到一个门槛，过了门槛就一定在误差之内。学完之后，你应该能独立写出 ε-N 和 ε-δ 证明，也能说清楚一个极限为什么不存在。

§1

数列极限的 ε-N 定义

看数列 \(a_n = \dfrac{(-1)^n}{n}\)：−1, 1/2, −1/3, 1/4, …。它一正一负地跳，但越跳越靠近 0。我们说它“趋于 0”。问题是，“越来越靠近”怎么写成一句能判断真假的话？

办法是把“靠近”量化：先规定一个误差 ε，在 A 周围画一条宽为 2ε 的带子，然后问从第几项开始，所有项都待在带子里。

定义 1.1
\[\lim_{n\to\infty} a_n = A \iff \forall\, \varepsilon>0,\ \exists\, N\in\mathbb{N}^+,\ \forall\, n>N:\ |a_n-A|\lt\varepsilon\]

读法：无论给出多小的 ε，都能找到下标 N，使第 N 项之后的每一项都落在带 (A−ε, A+ε) 里。

实验 1 · 找门槛 N拖动 ε，看 N 怎么变；也可以故意把 A 放错
ε = 0.20A = 0N = 5

你应该观察到

  1. ε 越小，N 越大。N 依赖于 ε，所以常写成 N(ε)。点“播放”看一遍。
  2. N 不唯一。图上标的是最小的可行 N，但任何更大的 N 也合格。定义只要求“存在”，证明时不必追求最小。
  3. 只看尾巴。前面有限项怎么跳都无所谓，改动有限项不影响极限。
  4. 发散的样子。切到 (−1)ⁿ + 1/n，把 ε 设成 0.5 以下，再随便拖 A：总有无穷多项在带外，找不到 N。

§2

写一个 ε-N 证明

可以把定义看成一场两人博弈：对手先出 ε，你再出 N。如果对手无论出什么 ε，你都能应对，A 就是极限。所谓证明，就是写出一个对任何 ε 都管用的出招公式。

先实战几轮。数列是 \(a_n = \dfrac{3n+1}{2n-1}\)，要证它趋于 \(\dfrac32\)。

实验 2 · 你来出 N提示：先化简 |aₙ − 3/2|
对手出的 ε =0.01
输入一个正整数 N，系统会检查 n > N 时是否都有 |aₙ − 3/2| < ε。

证明是怎么想出来的

分析时倒着想：从目标 \(|a_n-A|\lt\varepsilon\) 出发，推出 n 要多大。书写时正着写：先取定 N，再验证。

第 1 步 · 化简目标
\[\left|\frac{3n+1}{2n-1}-\frac32\right| = \frac{|2(3n+1)-3(2n-1)|}{2(2n-1)} = \frac{5}{2(2n-1)}\]
第 2 步 · 适当放大

当 n ≥ 1 时 \(2n-1\ge n\)，所以 \(\dfrac{5}{2(2n-1)} \le \dfrac{5}{2n}\)。放大的目的是让不等式好解。我们不需要最小的 N，只需要一个可行的 N。

第 3 步 · 解出 N

要 \(\dfrac{5}{2n}\lt\varepsilon\)，只需 \(n\gt\dfrac{5}{2\varepsilon}\)。于是取 \(N=\left\lceil \dfrac{5}{2\varepsilon}\right\rceil\)。

第 4 步 · 正式书写

证明　任给 ε > 0，取 \(N=\left\lceil \dfrac{5}{2\varepsilon}\right\rceil\)。当 n > N 时，

\[\left|\frac{3n+1}{2n-1}-\frac32\right| = \frac{5}{2(2n-1)} \le \frac{5}{2n} \lt \frac{5}{2N} \le \varepsilon.\]

由定义，\(\displaystyle\lim_{n\to\infty}\frac{3n+1}{2n-1}=\frac32\)。∎

回到实验 2，用公式 N = ⌈5/(2ε)⌉ 出招试试。它给出的 N 通常比最小值大，但一定能赢。

§4

函数极限的 ε-δ 定义

数列只有一个方向可走：n 越来越大。函数的自变量 x 可以从两侧逼近 x₀，所以“过了门槛 N”换成“离 x₀ 不到 δ”。

定义 1.2
\[\lim_{x\to x_0} f(x) = L \iff \forall\, \varepsilon>0,\ \exists\, \delta>0,\ \forall\, x:\ 0\lt|x-x_0|\lt\delta \Rightarrow |f(x)-L|\lt\varepsilon\]

读法：无论给出多小的 ε，都能找到 δ，只要 x 离 x₀ 不到 δ（但 x ≠ x₀），f(x) 离 L 就不到 ε。图上看：蓝色竖带里的那段曲线，必须完全落进橙色横带。

数列 aₙ → A函数 f(x) → L（x → x₀）
对手出ε > 0ε > 0
你出下标 N半径 δ > 0
“足够靠后 / 足够近”n > N0 < |x − x₀| < δ
要保证|aₙ − A| < ε|f(x) − L| < ε
实验 4 · 给 ε 找 δ先手动调 δ，再点“求最大可行 δ”对答案
ε = 1δ = 0.5L = 4最大可行 δ ≈ 0.236

你应该观察到

  1. x₀ 处的值无关紧要。sin x / x 在 0 处没有定义（图上空心点），极限照样是 1。条件里的 0 < |x − x₀| 把 x₀ 本身排除在外。
  2. 振荡不等于没有极限。x·sin(1/x) 在 0 附近振荡无穷多次，但振幅被 |x| 压住，所以 δ = ε 就够用。
  3. 跳跃点没有极限。当 ε ≤ 0.5 时，L 放在哪里都不行：x₀ 两侧的函数值分别靠近 −½ 和 ½，一条宽度不到 1 的横带装不下两边。

§5

写一个 ε-δ 证明

证明 \(\displaystyle\lim_{x\to 2} x^2 = 4\)。难点在于 \(|x^2-4|\) 拆开后，除了 \(|x-2|\) 还多出一个随 x 变化的因子。

第 1 步 · 分解
\[|x^2-4| = |x-2|\cdot|x+2|\]
第 2 步 · 先框住多余因子

|x + 2| 会随 x 变化。先规定 δ ≤ 1，这样 |x − 2| < 1，即 1 < x < 3，于是 \(|x+2|\lt 5\)。

第 3 步 · 解出 δ

此时 \(|x^2-4|\lt 5|x-2|\)。要它小于 ε，只需 \(|x-2|\lt\dfrac{\varepsilon}{5}\)。两个要求同时满足，取 \(\delta=\min\left\{1,\dfrac{\varepsilon}{5}\right\}\)。

第 4 步 · 正式书写

证明　任给 ε > 0，取 \(\delta=\min\left\{1,\dfrac{\varepsilon}{5}\right\}\)。当 \(0\lt|x-2|\lt\delta\) 时，由 |x − 2| < 1 得 |x + 2| < 5，从而

\[|x^2-4| = |x-2|\cdot|x+2| \lt \frac{\varepsilon}{5}\cdot 5 = \varepsilon.\]

由定义，\(\displaystyle\lim_{x\to2}x^2=4\)。∎

“先限制 δ ≤ 1”是 ε-δ 证明里最常用的技巧：先把和 x 有关的因子框住，再处理 |x − x₀|。回到实验 4，选 f(x) = x²，把 ε 调到 1 附近，比较最大可行 δ 和 min{1, ε/5}：后者更小，但足够用。

§6

归结原理：连接两种定义

定理 1.3（Heine 归结原理）

\(\displaystyle\lim_{x\to x_0} f(x)=L\) 成立，当且仅当对每一个满足 \(x_n\to x_0\)、\(x_n\ne x_0\) 的数列，都有 \(f(x_n)\to L\)。

用法：要证明函数极限不存在，只需找两个趋于 x₀ 的数列，让函数值趋于不同的数（或让某一列函数值不收敛）。

实验 5 · 两条路走向 0f(x) = sin(1/x)，两个数列都趋于 0
xₖ = 1/(kπ) = 0，f(xₖ) = 0 yₖ = 1/(2kπ + π/2) = 0，f(yₖ) = 1

两个数列都趋于 0，也都不等于 0。但 \(\sin(1/x_n)=\sin(n\pi)=0\)，\(\sin(1/y_n)=\sin(2n\pi+\tfrac{\pi}{2})=1\)。沿两条路走，函数值的极限分别是 0 和 1。由归结原理，\(\displaystyle\lim_{x\to0}\sin\frac1x\) 不存在。

对比实验 4 里的 x·sin(1/x)：同样的两个数列代进去，函数值都趋于 0，因为前面多了一个趋于 0 的因子 x。

练习题

练习 1　用 ε-N 定义证明 \(\displaystyle\lim_{n\to\infty}\frac{n^2+1}{2n^2-n}=\frac12\)。

提示

先通分化简差值，再在 n ≥ 2 的前提下把它放大成 1/n。

参考答案
\[\left|\frac{n^2+1}{2n^2-n}-\frac12\right| = \frac{n+2}{2n(2n-1)}\]

当 n ≥ 2 时 n + 2 ≤ 2n，且 2n − 1 ≥ n，所以上式 ≤ \(\dfrac{2n}{2n\cdot n}=\dfrac1n\)。任给 ε > 0，取 \(N=\max\{2,\lceil 1/\varepsilon\rceil\}\)，当 n > N 时差值 ≤ 1/n < 1/N ≤ ε。∎

练习 2　证明：若 \(a_n\to A\)，则 \(|a_n|\to|A|\)。反过来成立吗？

提示

三角不等式的变形：||a| − |b|| ≤ |a − b|。反例想想 (−1)ⁿ。

参考答案

任给 ε > 0，取 aₙ → A 对应的 N。当 n > N 时 \(\big||a_n|-|A|\big|\le|a_n-A|\lt\varepsilon\)，同一个 N 就够用。∎ 反过来不成立：aₙ = (−1)ⁿ 时 |aₙ| → 1，但 aₙ 本身发散。

练习 3　用 ε-δ 定义证明 \(\displaystyle\lim_{x\to4}\sqrt{x}=2\)。

提示

分子有理化：√x − 2 = (x − 4)/(√x + 2)。注意 δ 要保证 √x 有定义。

参考答案
\[|\sqrt{x}-2| = \frac{|x-4|}{\sqrt{x}+2} \le \frac{|x-4|}{2}\]

任给 ε > 0，取 \(\delta=\min\{4,2\varepsilon\}\)。δ ≤ 4 保证 x > 0。当 0 < |x − 4| < δ 时，|√x − 2| ≤ |x − 4|/2 < ε。∎

练习 4　用 ε-δ 语言写出“\(\displaystyle\lim_{x\to x_0} f(x)\ne L\)”。

提示

按 §3 的规则逐块取否定：∀ 变 ∃，∃ 变 ∀，蕴含式 P ⇒ Q 的否定是 P 且非 Q。

参考答案
\[\exists\,\varepsilon_0>0,\ \forall\,\delta>0,\ \exists\,x:\ 0\lt|x-x_0|\lt\delta\ \text{and}\ |f(x)-L|\ge\varepsilon_0\]

即存在一个误差 ε₀，无论 δ 多小，x₀ 的 δ 去心邻域里总有点的函数值偏离 L 至少 ε₀。
