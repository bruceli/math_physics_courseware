极限的性质与运算

第一章学会了用 ε 语言判断一个数是不是极限。这一章用同样的语言推出极限的一般性质：极限只有一个、收敛数列有界、极限能保持正负号、极限可以做四则运算，以及最常用的求极限工具夹逼准则。最后用它算出第一个重要极限 sin x / x → 1。

§1

唯一性：一个数列不能趋于两个数

直觉上显然：数列的尾巴不可能同时挤在两个不同的地方。证明的关键是选对 ε，让两条误差带分开。

定理 2.1（唯一性）

若 \(\lim a_n = A\) 且 \(\lim a_n = B\)，则 \(A=B\)。

实验 1 · 两条带子aₙ = 1 + (−1)ⁿ/√n，真正的极限 A = 1；B 是冒充者
ε = 0.30|A − B|/2 = 0.25A 的门槛 N = 0B 的门槛 N = 0
第 1 步 · 反设并选 ε

假设 \(A\ne B\)。取 \(\varepsilon=\dfrac{|A-B|}{2}>0\)，这正是让两条带刚好不相交的宽度。

第 2 步 · 两个门槛

由 \(a_n\to A\)，存在 \(N_1\)，当 \(n>N_1\) 时 \(|a_n-A|\lt\varepsilon\)；由 \(a_n\to B\)，存在 \(N_2\)，当 \(n>N_2\) 时 \(|a_n-B|\lt\varepsilon\)。

第 3 步 · 推出矛盾

取 \(n>\max\{N_1,N_2\}\)，两式同时成立，于是

\[|A-B|\le|a_n-A|+|a_n-B|\lt 2\varepsilon=|A-B|,\]

矛盾。所以 \(A=B\)。∎

“取 max{N₁, N₂}”是处理两个条件同时成立的标准动作，本章后面会一直用。

§2

有界性与保号性

这两条性质的证明套路相同：先对一个特别选取的 ε 用定义，管住门槛之后的无穷多项；门槛之前只剩有限项，单独处理。

定理 2.2（有界性）

收敛数列必有界：若 \(a_n\to A\)，则存在 \(M>0\)，对所有 n 有 \(|a_n|\le M\)。

定理 2.3（保号性）

若 \(a_n\to A>0\)，则存在 N，当 \(n>N\) 时 \(a_n>\dfrac A2>0\)。A < 0 的情形同理。

实验 2 · 管住尾巴，再收拾有限项切换上方的性质，看证明里的 ε 怎么取

证明

有界性　对 ε = 1 用定义：存在 N，当 n > N 时 |aₙ − A| < 1，从而 \(|a_n|\lt|A|+1\)。门槛之前只有 \(a_1,\dots,a_N\) 这有限项。取 \(M=\max\{|a_1|,\dots,|a_N|,|A|+1\}\)，所有项都满足 \(|a_n|\le M\)。∎

保号性　对 ε = A/2 用定义：存在 N，当 n > N 时 \(|a_n-A|\lt\dfrac A2\)，于是 \(a_n\gt A-\dfrac A2=\dfrac A2\gt0\)。∎

推论：保不等式

若 \(a_n\to A\)，\(b_n\to B\)，且从某项起 \(a_n\le b_n\)，则 \(A\le B\)。证明：若 A > B，对 \(b_n-a_n\to B-A\lt0\) 用保号性，从某项起 \(b_n\lt a_n\)，矛盾。

注意严格不等号不能保持：\(\dfrac1n\gt0\) 对每个 n 成立，但极限是 0。取极限时，< 要放宽成 ≤。

§3

四则运算法则

定理 2.4（四则运算）

若 \(a_n\to A\)，\(b_n\to B\)，则

\[a_n\pm b_n\to A\pm B,\qquad a_nb_n\to AB,\qquad \frac{a_n}{b_n}\to\frac AB\ \ (B\ne0).\]

加减法几乎直接由三角不等式得到。乘法要多想一步：\(a_nb_n\) 和 \(AB\) 差多少？把乘积看成长方形面积，差就看得见了。

实验 3 · 乘积的误差是三块面积a = A + Δa，b = B + Δb（为了画图只画 Δ ≥ 0 的情形）

图上的等式就是 \(ab-AB=A\,\Delta b+B\,\Delta a+\Delta a\,\Delta b\)。证明时更方便的写法是把它并成两项。

第 1 步 · 拆成两项
\[a_nb_n-AB=a_n(b_n-B)+B(a_n-A)\]
第 2 步 · 用有界性管住 aₙ

第一项里的 \(a_n\) 会变。但 \(a_n\) 收敛，由定理 2.2 存在 M，使 \(|a_n|\le M\) 对所有 n 成立。于是

\[|a_nb_n-AB|\le M\,|b_n-B|+|B|\,|a_n-A|.\]
第 3 步 · 取两个门槛的最大值

任给 ε > 0，存在 \(N_1\)、\(N_2\) 分别使 \(|a_n-A|\lt\varepsilon\)、\(|b_n-B|\lt\varepsilon\)。当 \(n>\max\{N_1,N_2\}\) 时

\[|a_nb_n-AB|\lt (M+|B|)\,\varepsilon.\]

右边是 ε 的常数倍，由第一章 §3 的等价说法，\(a_nb_n\to AB\)。∎

除法的关键是分母不能离 0 太近：由保号性的推广，B ≠ 0 时从某项起 |bₙ| > |B|/2。这一步留作练习 2。

§4

夹逼准则与 sin x / x

定理 2.5（夹逼准则）

若从某项起 \(a_n\le c_n\le b_n\)，且 \(a_n\to L\)，\(b_n\to L\)，则 \(c_n\to L\)。函数极限同理。

证明：任给 ε，取门槛的最大值，使 \(L-\varepsilon\lt a_n\) 和 \(b_n\lt L+\varepsilon\) 同时成立，于是 \(L-\varepsilon\lt a_n\le c_n\le b_n\lt L+\varepsilon\)。

夹逼准则的价值在于：c 本身难算，但能找到两个容易算、而且极限相同的界。最经典的例子是 \(\dfrac{\sin x}{x}\)。第一章实验 4 里你已经看到它在 0 附近趋于 1，现在来证明它。

实验 4 · 单位圆里的三块面积拖动角 x（弧度），左图比较面积，右图看夹逼
第 1 步 · 比较面积

设 \(0\lt x\lt\dfrac\pi2\)。单位圆中，三角形 OAP ⊂ 扇形 OAP ⊂ 三角形 OAT，面积依次为

\[\frac{\sin x}{2}\lt\frac{x}{2}\lt\frac{\tan x}{2}.\]
第 2 步 · 变形成夹逼的样子

各项乘 \(\dfrac{2}{\sin x}\gt0\) 再取倒数（不等号反向）：

\[\cos x\lt\frac{\sin x}{x}\lt1.\]

三个函数都是偶函数，所以 \(-\dfrac\pi2\lt x\lt0\) 时同样成立。

第 3 步 · 下界趋于 1

还要说明 \(\cos x\to1\)。由 \(0\le1-\cos x=2\sin^2\dfrac x2\le2\left(\dfrac x2\right)^2=\dfrac{x^2}{2}\)，再用一次夹逼即得。这里用到了第 1 步的 \(|\sin t|\le|t|\)。

第 4 步 · 结论

两边的界都趋于 1，由夹逼准则

\[\lim_{x\to0}\frac{\sin x}{x}=1.\ \ ∎\]

数列也常用夹逼。例如 \(-\dfrac1n\le\dfrac{\sin n}{n}\le\dfrac1n\)，两边都趋于 0，所以 \(\dfrac{\sin n}{n}\to0\)。

练习题

练习 1　证明 \(\displaystyle\lim_{n\to\infty}\sqrt[n]{n}=1\)。

提示

设 \(\sqrt[n]{n}=1+h_n\)，\(h_n\ge0\)。用二项式展开只保留一项，得到 h_n 的上界，再夹逼。

参考答案

n ≥ 2 时，\(n=(1+h_n)^n\ge\dfrac{n(n-1)}{2}h_n^2\)，所以 \(0\le h_n\le\sqrt{\dfrac{2}{n-1}}\)。右边趋于 0，由夹逼 \(h_n\to0\)，即 \(\sqrt[n]{n}\to1\)。∎

练习 2　证明商的法则：若 \(a_n\to A\)，\(b_n\to B\ne0\)，则 \(\dfrac{a_n}{b_n}\to\dfrac AB\)。

提示

先证 \(\dfrac{1}{b_n}\to\dfrac1B\)，再用乘法法则。对 ε = |B|/2 用定义，得到从某项起 |bₙ| > |B|/2。

参考答案

存在 \(N_0\)，n > N₀ 时 \(|b_n-B|\lt\dfrac{|B|}2\)，从而 \(|b_n|\gt\dfrac{|B|}2\)。于是

\[\left|\frac1{b_n}-\frac1B\right|=\frac{|b_n-B|}{|b_n|\,|B|}\le\frac{2}{|B|^2}\,|b_n-B|.\]

右边是 \(|b_n-B|\) 的常数倍，故 \(\dfrac1{b_n}\to\dfrac1B\)。再由乘法法则，\(\dfrac{a_n}{b_n}=a_n\cdot\dfrac1{b_n}\to\dfrac AB\)。∎

练习 3　求 \(\displaystyle\lim_{n\to\infty}\sqrt n\left(\sqrt{n+1}-\sqrt n\right)\)。

提示

分子有理化，再分子分母同除以 √n。

参考答案
\[\sqrt n\left(\sqrt{n+1}-\sqrt n\right)=\frac{\sqrt n}{\sqrt{n+1}+\sqrt n}=\frac{1}{\sqrt{1+\frac1n}+1}\to\frac12.\]

最后一步用到四则运算法则和 \(\sqrt{1+\frac1n}\to1\)。

练习 4　求 \(\displaystyle\lim_{x\to0}\frac{1-\cos x}{x^2}\)。

提示

用半角公式把 1 − cos x 化成 sin²，凑出 sin t / t。

参考答案
\[\frac{1-\cos x}{x^2}=\frac{2\sin^2\frac x2}{x^2}=\frac12\left(\frac{\sin\frac x2}{\frac x2}\right)^2\to\frac12.\]
